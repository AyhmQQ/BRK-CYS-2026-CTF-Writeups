# BRK-CYS 2026 — Cryptography Archive
**Challenge writeups and design notes by Ayham Alderbashi**

This repository collects material from my cryptography challenge contributions to BRK-CYS 2026, organized through Breakers. It includes writeups, supplied challenge data, and selected Python/SageMath scripts.

## Reading the material

Start with the README inside each folder. File names and folder names are preserved from the original archive so existing links continue to work.

**Documentation status:** the presence of a solver or a displayed flag does not establish that the result has been independently reproduced. Difficulty labels in the original writeups are event labels, not measured benchmarks. This archive should be read as learning material, with the assumptions and limitations of each entry in mind.

The Gwen Stacy entry is a design discussion, not a demonstrated end-to-end solution. Claims about practical impossibility or resistance to particular tools are not established by the material included here.
